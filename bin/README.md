# باینری‌های آماده

باینری‌های استاتیک BackPack، بیلدشده از سورس. نه Go لازم دارند نه libc — روی هر
لینوکس ۶۴ بیتی مستقیم اجرا می‌شوند.

## نصب

```bash
sudo ./bin/install-backpack.sh
```

معماری را خودش تشخیص می‌دهد، چک‌سام را تأیید می‌کند و روی
`/usr/local/bin/backpack` می‌نشاند. **هیچ اینترنتی لازم ندارد** — و همین نکته‌ی
اصلی است: لحظه‌ای که به تونل احتیاج داری، دقیقاً همان لحظه‌ای است که گیت‌هاب کمتر
از همیشه جواب می‌دهد. اسکریپت‌های `deploy/` هم اول همین را امتحان می‌کنند و فقط
اگر نشد سراغ شبکه می‌روند.

دستی، اگر ترجیح می‌دهی:

```bash
sudo install -m 0755 bin/backpack-linux-amd64 /usr/local/bin/backpack
sudo mkdir -p /etc/backpack
backpack -v
```

## چه چیزی بیلد شده

| | |
|---|---|
| نسخه | `v1.6.1` |
| منبع | https://github.com/AminMGMT/BackPack |
| کامیت | `3203268eda81d6e26af6584a94cf24db9fb13fc5` |
| Go | `go1.24.7 linux/amd64` |
| فرمان | `make release` (همان چیزی که خود پروژه برای انتشار استفاده می‌کند) |
| فلگ‌ها | `CGO_ENABLED=0 -trimpath -ldflags "-s -w"` |

| فایل | معماری | حجم |
|---|---|---|
| `backpack-linux-amd64` | x86-64 | ۱۵ مگابایت |
| `backpack-linux-arm64` | aarch64 | ۱۳ مگابایت |

هر دو `statically linked` و `stripped`. نسخه‌ی amd64 اجرا و تست شد (`-v` →
`v1.6.1`).

## تأیید چک‌سام

```bash
cd bin && sha256sum -c SHA256SUMS
```

اگر این کلون از یک میرور یا فلش به دستت رسیده، قبل از اجرا با root حتماً این را
بزن. اسکریپت نصب هم خودش این کار را می‌کند و اگر نخواند، نصب نمی‌کند.

## بیلد مجدد از سورس

`-trimpath` و `-ldflags "-s -w"` بیلد را قابل بازتولید می‌کنند — با همان کامیت و
همان نسخه‌ی Go باید دقیقاً همین چک‌سام‌ها دربیایند:

```bash
git clone https://github.com/AminMGMT/BackPack.git
cd BackPack && git checkout 3203268eda81d6e26af6584a94cf24db9fb13fc5
make release
sha256sum dist/backpack-linux-*
```

## لایسنس

BackPack تحت **AGPL-3.0** منتشر شده، نوشته‌ی Amin Mohammadi. متن کامل در
`LICENSE.BackPack` و `NOTICE.BackPack` کنار همین فایل است.

AGPL اجازه‌ی توزیع مجدد باینری را می‌دهد، به شرط اینکه سورس متناظرش در دسترس
باشد. کامیت دقیقی که این باینری‌ها از آن ساخته شده‌اند بالا آمده و مخزن بالادست
عمومی است. اگر روزی سورس را تغییر دادی و باینری تغییریافته را پخش کردی، همان
تغییرات هم باید تحت AGPL منتشر شوند.
