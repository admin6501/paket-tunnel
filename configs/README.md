# نمونه‌کانفیگ‌ها

اسکریپت‌های `deploy/` این فایل‌ها را خودکار می‌سازند. این نسخه‌ها برای وقتی‌اند
که می‌خواهی دستی تنظیم کنی یا ببینی هر کلید چه می‌کند.

| فایل | نقش | کِی |
|---|---|---|
| `iran-wssmux.toml.example` | سرور (ایران) | مسیر اصلی |
| `kharej-wssmux.toml.example` | کلاینت (خارج) | مسیر اصلی، پشت CDN |
| `kharej-stealth.toml.example` | کلاینت (خارج) | وقتی DPI مسیر اصلی را می‌کشد |

مقصد: `/etc/backpack/<name>.toml` — و بعد `systemctl restart backpack-<name>`.

## انتخاب ترنسپورت

| ترنسپورت | روی سیم | برای |
|---|---|---|
| `wssmux` | HTTPS با اثرانگشت واقعی کروم | پیش‌فرض؛ تنها گزینه‌ای که از CDN رد می‌شود |
| `stealth` | بایت تصادفی، بدون امضا | وقتی DPI الگو را می‌گیرد |
| `kcp` | UDP با FEC | مسیر پرلاست؛ خطا را بدون تأخیر retransmit ترمیم می‌کند |
| `tcpmux` | TCP خام | فقط مسیر تمیز؛ ساده و سریع، ولی امضادار |

## دو قانون

**ترنسپورت دو طرف باید یکی باشد.** اگر یک سمت را عوض کردی، سمت دیگر را هم عوض
کن، وگرنه تونل بالا نمی‌آید.

**همه‌ی آدرس‌های `fallback_addrs` باید به یک سرور برسند.** توکن و پورت‌های
expose‌شده به یک ماشین تعلق دارند. IP دوم همان سرور، پورت دیگرش، یا لبه‌ی CDN
جلویش — هر سه درست‌اند. ماشین دیگر، نه.
