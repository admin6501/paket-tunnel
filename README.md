# Spoof-Tunnel — Iran ↔ Foreign (mutual IP-spoofing carrier for WireGuard)

A low-level (L3/L4) tunneling toolkit that carries encrypted **WireGuard**
traffic inside **source-spoofed ICMP/UDP** carrier packets, in order to cross a
**whitelist-based national gateway** during international connectivity cuts.

- **Core:** pure **C**, single static binary (`spooftun`), raw sockets
  (`AF_INET`/`AF_PACKET`) + BPF, manual packet build/parse (bypasses kernel
  conntrack). Prebuilt for **amd64** and **arm64**.
- **Manager:** interactive **Bash + whiptail** CLI (`spoof-tunnel`).
- **OS:** Ubuntu 22.04, root required, on **both** servers.

> ⚠️ This only works if the gateway filtering is *whitelist-based* and your
> provider allows egress packets with a spoofed source. A 100% absolute
> IP-blackout cannot be bypassed by any software.

---

## How it works

```
user ─▶ Iran server (relay) ─┐  packets spoofed with a whitelisted Source IP
                             ▼  (encapsulated in ICMP/UDP)
                    national gateway ── passes (source looks whitelisted)
                             ▼
                  foreign server (exit) ─▶ free internet
```

WireGuard runs over a raw "pipe": both endpoints craft carrier packets whose
source IP looks whitelisted. Because a normal TCP/UDP stack breaks under
spoofing, the C core builds/reads packets by hand and uses `rp_filter=0` so
spoofed packets are accepted on RX.

Fixed tunnel IPs (configurable in the menu):
- relay (Iran): `10.20.20.1`
- exit (foreign): `10.20.20.2`

### Data path (per server)
```
WireGuard (ListenPort=WG_PORT, Endpoint=127.0.0.1:LOCAL_PORT)
   │  UDP ──▶ 127.0.0.1:LOCAL_PORT  (spooftun local socket)
   ▼
spooftun ──(encapsulate + spoof source)──▶ raw AF_INET ──▶ peer public IP
                                                   │ gateway
peer spooftun ──(AF_PACKET RX + decapsulate)──▶ 127.0.0.1:WG_PORT (peer WG)
```

## Quick start

### روش ۱ — نصب آنلاین (تک‌خطی از گیت‌هاب)
روی **هر دو سرور** (اول خارج، بعد ایران) کافیست بزنی:

```bash
curl -fsSL https://raw.githubusercontent.com/admin6501/paket-tunnel/main/install.sh | sudo bash
```

اسکریپت خودش ریپو را در `/opt/paket-tunnel` کلون می‌کند، وابستگی‌ها و باینری
مناسب معماری را نصب می‌کند. سپس منو را با این دستور باز کن:

```bash
sudo spoof-tunnel
```

### روش ۲ — نصب آفلاین (از فایل‌های کلون‌شده)
```bash
git clone https://github.com/admin6501/paket-tunnel.git
cd paket-tunnel
sudo ./install.sh
```

> اجبار حالت: `sudo ./install.sh --online` یا `--offline`.
> ریپو/برنچ دلخواه: `REPO_URL=... REPO_BRANCH=... sudo bash install.sh`.

Then in the menu:

1. **Install & auto-setup** — deps, binary, sysctl (`ip_forward=1`,
   `rp_filter=0`, BBR).
2. **Select role** — `exit` on the foreign server (enter Iran's public IP),
   `relay` on the Iran server (enter the foreign public IP).
3. **Spoof-Tester** — on exit run *listen*, on relay run *send* with candidate
   whitelisted ranges; see which claimed source IPs actually arrive.
4. **Set carrier** — UDP (default) or ICMP.
5. **Set fixed IPs + WireGuard keys** — generates keys; exchange the printed
   public key with the other server; set the spoofed source IP found in step 3.
6. **Port forwarding** — add Xray input ports (e.g. `tcp:443`).
7. **Live status** — service state, internal ping `10.20.20.x`, latency,
   transfer.
8. **Monitoring + watchdog** — install/enable systemd services; the watchdog
   pings the internal peer and auto-restarts on failure.
9. **Network optimization** — BBR, `MTU 1280`, `rp_filter=0`.
10. **Backup / restore**.
11. **Uninstall & cleanup**.

Verify the tunnel: `ping 10.20.20.2` (from relay) / `ping 10.20.20.1` (from exit).

## Repository layout

```
core/spooftun.c        pure-C core (run / probe-send / probe-listen)
core/Makefile          native + cross (amd64/arm64) build
bin/spooftun-amd64      prebuilt static binary (x86_64)
bin/spooftun-arm64      prebuilt static binary (aarch64)
scripts/spoof-tunnel.sh interactive whiptail manager
systemd/                reference unit files (also generated by the manager)
install.sh             one-shot bootstrap
```

## Build from source

```bash
cd core
make            # native binary -> ./spooftun
make all        # cross-build -> ../bin/spooftun-amd64 and spooftun-arm64
                # (needs gcc-x86-64-linux-gnu / gcc-aarch64-linux-gnu)
```

## Core CLI (advanced/manual)

```bash
spooftun run          --carrier udp --peer <peer_pub_ip> --spoof <whitelisted_ip> \
                      --iface eth0 --lport 51821 --wgport 51820 --cport 8443
spooftun probe-send   --carrier udp --peer <exit_pub_ip> --spoof <candidate_ip> --count 20
spooftun probe-listen --carrier udp --iface eth0 --seconds 30
```

## Notes & assumptions

- Root on both servers; provider permits spoofed egress.
- Xray is installed/configured separately; this tool only builds the transport.
- The kernel must not answer carrier packets — the manager adds an `iptables`
  DROP rule on the public interface for the chosen carrier (internal
  `10.20.20.x` pings on `wgtun` are unaffected).
- MTU is set to 1280 to avoid fragmentation.
