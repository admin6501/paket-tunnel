# فروشگاه وب آسان‌گذر

فروشگاه در `/shop/` از همان Worker و پایگاه دادهٔ ربات فروش استفاده می‌کند. بسته‌ها، دسته‌ها، سفارش‌ها، کیف پول، کد تخفیف، تست و سرویس‌ها در پایگاه دادهٔ فعلی ربات می‌مانند. پس از ورود با حساب تلگرام، «پنل مدیریت» فقط برای ادمین‌های تأییدشدهٔ همان ربات نمایش داده می‌شود. فیش‌های وب هم در تلگرام به مدیران می‌رسند و هم در بخش «فیش‌های وب» مدیر دیده می‌شوند. پخش رسانه‌ای همگانی همچنان از تلگرام انجام می‌شود.

## نصب روی سروری که ربات در آن با Node اجرا می‌شود

۱. پیش از آپدیت، از دیتابیس ربات و ریشهٔ فعلی سایت بکاپ بگیرید. کد جدید `telegram-bot` از مخزن `admin6501/vpn-ui` به‌همراه بستهٔ وب از `admin6501/paket-tunnel` لازم است. دیتابیس تازه برای فروشگاه نسازید.

۲. این سه کلید را به تنظیمات **موجود** ربات در `/etc/vpn-ui-bot/config.json` اضافه کنید. مقادیر توکن، رمز و ادمین قبلی را نگه دارید.

```json
{
  "WEB_SHOP_ORIGIN": "https://asan-gozar.ir",
  "WEB_SHOP_BOT": "asangozarsalesbot",
  "WEB_SHOP_PORT": 8787
}
```

ربات هنگام شروع جدول‌های وب را اضافه می‌کند و API را فقط روی `127.0.0.1:8787` باز می‌کند. فایل‌های اصلی ربات و نصب Node باید همان نسخهٔ جدید باشند. فعال‌سازی وب مستلزم باز بودن HTTPS دامنه و توانایی ربات در ارسال پیام کد ورود است.

۳. آرشیو به‌روز را در ریشهٔ تأییدشدهٔ دامنه باز کنید تا `shop/index.html` در ریشه باشد. فایل `asan-gozar-shop.nginx.conf` را از داخل **server block فعلی HTTPS** با `include` بخوانید. تنظیمات TLS و ریشهٔ فعلی سایت را حفظ کنید. اگر دامنهٔ `www` هم به سایت می‌رسد، آن را به دامنهٔ اصلی هدایت کنید تا مبدأ ورود یکسان باشد. اگر ربات روی سرور جداست، نمونهٔ loopback عیناً قابل استفاده نیست و API باید از یک مسیر HTTPS تأییدشده در دسترس باشد.

۴. تنظیمات را با `nginx -t` بررسی کنید و Nginx و سرویس ربات را طبق استقرار موجود بارگذاری کنید. در `https://asan-gozar.ir/shop/` ابتدا ورود، فهرست دسته‌های فروش و سپس یک خرید آزمایشی با حساب تست را بررسی کنید. پذیرش فیش و شارژ از همان منطق و نقش‌های فعلی ربات پیروی می‌کند.

## ربات میزبانی‌شده روی Cloudflare

قبل از انتشار Worker، اسکیمای جداگانهٔ وب را به همان D1 فعلی اضافه کنید. از پوشهٔ `telegram-bot`:

```sh
node --input-type=module -e 'import {WEB_SHOP_SCHEMA} from "./web-shop-schema.js"; process.stdout.write(WEB_SHOP_SCHEMA)' > /tmp/asan-gozar-web-shop.sql
npx wrangler d1 execute YOUR_EXISTING_DB --remote --file /tmp/asan-gozar-web-shop.sql
```

نام واقعی D1 را جایگزین کنید. در تنظیمات Worker، `WEB_SHOP_ORIGIN` و `WEB_SHOP_BOT` را مطابق بالا قرار دهید. بخش `/shop/api/` در Nginx باید به آدرس HTTPS همان Worker با SNI و بررسی گواهی فعال پراکسی شود. وب‌هوک فعلی تلگرام را نگه دارید.

ورود وب به Telegram نیاز دارد. پرداخت اینترنتی جدیدی اضافه نشده است؛ امکانات پرداخت همان کیف پول و کارت‌به‌کارت ربات‌اند. فیش ارسالی از وب در نسخهٔ وب تا ۳۰ روز قابل مشاهده است. فرستادن فیش یا ثبت سفارش به‌معنای تأیید پرداخت نیست.
