نصب روی Nginx:
صفحات معرفی استاتیک‌اند. بخش shop/ برای ورود و ثبت سفارش به سرور مستقل فروشگاه نیاز دارد.
روی نصب موجود، ابتدا با nginx -T ریشه server block دامنه asan-gozar.ir را بررسی و از فایل‌های فعلی بکاپ بگیرید. فایل‌های آرشیو را در همان ریشه با دسترسی خواندن برای Nginx قرار دهید و تنظیمات HTTPS موجود را نگه دارید.
برای نصب تازه، آرشیو را در /var/www باز کنید تا index.html مستقیماً در /var/www/asan_gozar_website قرار بگیرد. نمونه تنظیم HTTP در فایل asan-gozar.nginx.conf کنار آرشیو است. پس از ایجاد و فعال‌سازی server block، با nginx -t تنظیمات را بررسی و سپس با systemctl reload nginx بارگذاری کنید. برای دامنهٔ عمومی، HTTPS را در همان server block یا با ابزار مدیریت گواهی سرور تنظیم کنید.
